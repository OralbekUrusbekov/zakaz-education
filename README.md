# Tech School — образовательная платформа

Сайт учебного центра с тремя личными кабинетами: студента, преподавателя и руководства.
Адрес школы — Алматы, улица Манаса 34/1 (угол Джандосова), кампус МУИТ.

- **Фронтенд** — Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + Recharts, порт **3040**
- **Бэкенд** — FastAPI + SQLAlchemy 2 + JWT, порт **8020** (SQLite по умолчанию, PostgreSQL опционально)

## Запуск в Docker (рекомендуемый способ)

```bash
docker compose up -d --build
```

Поднимаются три контейнера: PostgreSQL, FastAPI и Next.js. База наполняется демо-данными
автоматически при первом старте.

| Сервис | Адрес |
|---|---|
| Сайт | http://localhost:3040 |
| API | http://localhost:8020 (документация — `/docs`) |
| PostgreSQL | localhost:5442 (`techschool` / `techschool`, база `education`) |

```bash
docker compose logs -f backend   # логи
docker compose down              # остановить
docker compose down -v           # остановить и стереть базу (при следующем старте данные пересоздадутся)
```

Если фронтенд должен обращаться к API по другому адресу (например, с другого устройства),
пересоберите его с нужным адресом:

```bash
NEXT_PUBLIC_API_URL=http://192.168.1.10:8020/api/v1 docker compose up -d --build frontend
```

## Запуск без Docker

### 1. Бэкенд

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.seed --reset        # демо-данные (пересоздаёт базу)
.venv/bin/python -m uvicorn app.main:app --port 8020 --reload
```

Документация API: http://localhost:8020/docs

### 2. Фронтенд

```bash
pnpm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8020/api/v1
pnpm dev
```

Сайт: http://localhost:3040

## Тесты

```bash
# бэкенд: 61 тест (pytest)
cd backend && .venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest

# фронтенд: 107 тестов (vitest + testing-library)
pnpm test
```

Бэкенд-тесты поднимают отдельную SQLite-базу с демо-данными и проверяют авторизацию и роли,
кабинет студента (расписание, посещаемость, ДЗ с файлом, оценки, оплата), кабинет преподавателя
(журнал, проверка работ, посещаемость, комментарии), аналитику руководства и публичные заявки на события.

Фронтенд-тесты покрывают форматирование и словари статусов, контент (новости, события, программы, клубы),
API-клиент (заголовки, ошибки, 401, multipart), пагинацию, модальное окно регистрации, календарь событий, UI-кит
и локализацию (полнота словарей, переключатель «Рус/Қаз», откат к русскому при отсутствии перевода).

## Что есть в кабинетах

**Студент** — расписание (неделя/месяц), посещаемость (кольцо + календарь-тепловая карта), прогресс по курсам с программой занятий, домашние задания (сдача текстом и файлом), оценки (журнал предметы × даты, динамика), оплата (счета, история, демо-оплата).

**Преподаватель** — обзор и группы, расписание, список студентов с фильтрами и профилем, журнал оценок (клик по ячейке = выставление оценки), проверка домашних заданий с оценкой и комментарием, отметка посещаемости, комментарии студентам.

**Руководство** — отдельные страницы: дашборд с KPI и графиками, «Курсы» (популярность и завершаемость), «Преподаватели» (нагрузка и результаты), «Зона риска» (студенты, которым нужно внимание). Фильтры по периоду и курсу, экспорт отчёта в CSV.

Оценки во всей системе — по **десятибалльной шкале**.

## Публичный сайт

Главная, «О школе» (таймлайн истории), «Обучение» с отдельной страницей на каждую из четырёх программ
(`/learning/primary`, `/middle`, `/high`, `/studios`), новости с фильтрами, поиском, видом «карточки/список»,
пагинацией по 9 и страницей каждой новости, события в виде календаря с регистрацией через модальное окно,
клубы с отдельными страницами (`/clubs/...`), объединённая страница «Ученикам и родителям» (`/community`,
клубы + календарь семинаров) и «Обучение и поступление» (`/learning`), контакты.

Сайт двуязычный: переключатель «Рус / Қаз» в шапке, выбор сохраняется в браузере.
Русский — основной язык, казахский берётся из словарей `lib/i18n/`:

- `dict.ts` — строки интерфейса (шапка, подвал, формы, поиск, календарь) в виде `{ ru, kk }`;
- `kk.ts` — перевод текстов страниц: ключ — русская строка из разметки, значение — казахский перевод;
  если ключа нет, показывается русский оригинал;
- `tr()` / `<T>` подставляют перевод, `useLocale().pick()` — достаёт нужный язык из `{ ru, kk }`.

Личный кабинет и данные, приходящие с бэкенда, не переводятся — они всегда на русском.

## Структура

```
app/                 публичный сайт + /login + кабинеты (student, teacher, admin)
components/site/     календарь событий, модальное окно регистрации, пагинация
components/admin/    общие фильтры и загрузка данных для страниц руководства
tests/               vitest-тесты фронтенда
backend/tests/       pytest-тесты API
components/cabinet/  UI-кит кабинетов (карточки, таблицы, модалки, расписание)
lib/api/             клиент FastAPI по ролям
lib/types.ts         типы, совпадающие со схемами бэкенда
lib/i18n/            переключение языка и словари ru/kk для публичного сайта
docker-compose.yml   PostgreSQL + FastAPI + Next.js
backend/app/
  models.py          таблицы (пользователи, курсы, группы, занятия, оценки, ДЗ, платежи)
  schemas.py         Pydantic-схемы ответов
  routers/           auth, students, teachers, analytics
  seed.py            генератор демо-данных относительно текущей даты
```

## PostgreSQL вместо SQLite

```bash
# backend/.env
DATABASE_URL=postgresql+psycopg://user:pass@localhost:5432/education
```

Раскомментируйте `psycopg[binary]` в `backend/requirements.txt`, установите зависимости и выполните `python -m app.seed --reset`.
